# นักสืบคฤหาสน์ — Cluedo Web Game 🔍

เกม Clue/Cluedo ในรูปแบบ Web App ภาษาไทย เล่นได้บน GitHub Pages

## เล่นได้เลย
เปิดไฟล์ `index.html` ในเบราว์เซอร์ หรือ host บน GitHub Pages

## วิธีขึ้น GitHub Pages

1. สร้าง Repository ใหม่บน GitHub (ชื่ออะไรก็ได้)
2. Upload ไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้นไป
3. ไปที่ **Settings → Pages → Source: main branch / root**
4. เกมจะพร้อมเล่นที่ `https://<username>.github.io/<repo-name>`

## วิธีเล่น

### ตั้งค่า
- เลือกจำนวนผู้เล่น (2–6 คน)
- ตั้งชื่อ และเลือก 👤 ผู้เล่น หรือ 🤖 AI
- กด **เริ่มเกม**

### การเล่น (แต่ละเทิร์น)
1. **🎲 ทอยลูกเต๋า** — ทอยลูกเต๋า 2 ลูก
2. **เลือกช่อง** — คลิกช่องสีน้ำเงินที่ต้องการเดิน
3. **💬 ตั้งข้อสงสัย** (ถ้าเข้าห้อง) — เสนอ ใคร + อาวุธ + ห้องนี้
4. **ผู้เล่นอื่นหักล้าง** — ถ้าถือการ์ดที่ตรงกัน ต้องแสดง
5. **📓 จดในสมุด** — จดบันทึกสิ่งที่รู้ไว้
6. **⚖️ กล่าวหา!** — เมื่อมั่นใจ เดาคำตอบสุดท้าย (ผิด = หลุดเกม!)

### กฎสำคัญ
- การ์ด 21 ใบถูกสุ่มแจกให้ผู้เล่น 1 ใบถูกซ่อนเป็นคำตอบ
- เมื่อ **ตั้งข้อสงสัย** ผู้ต้องสงสัยและอาวุธจะถูกย้ายมาห้องนั้น
- **กล่าวหาผิด** = หลุดจากเกม แต่ยังช่วยหักล้างข้อสงสัยได้
- ใช้ **Secret Passage** (มุมห้อง) เดินข้ามแผนที่

```
│   ├── ai.js       # ตรรกะ AI
│   ├── ui.js       # ควบคุม UI และ Modal
│   └── game.js     # ตัวควบคุมเกมหลัก
└── README.md
```
